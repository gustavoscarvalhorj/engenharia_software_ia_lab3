# Crie uma página web de reservas de hotéis, o objetivo aqui é garantir que o usuário consiga:
    - fazer uma pesquisa por destino e data;
    - Listar os hotéis
    - Avançar para a tela de checkout
    - Não precisa construir uma solução mega robusta;
    - A ideia é ser uma PoC de validação e dados mockados;
    - Crie mocks de APIs para essa solução;
    = Faça algo simples;

Regras de negócio;
    - Destinos: Considerar apenas Rio de Janeiro, Goias e Brasilia.
    - Datas: 
        - Não aceitar data no passado;
        - Aceitar reservas de late minutes (para o dia)
    - Minimo de Adultos: 1
    - Minimo de Crianças: 0
